# antislop audit 002: mobile layout

Date: 2026-10-05
Skill: antislop-layoutmobile (read with antislop core)
Mode: AFTER (audit + fix all, as requested)
Scope: 360 / 375 / 390 px widths, 667 / 844 px heights.

Priority: Hard Gate (R-03 mobile) = HIGH.

## Findings

### M-01 — HIGH — R-03 (targets/overlap)
Fixed bottom bars collide on narrow phones. At 360px the
preview badge (right edge 210) overlaps the "Your brief" dock (left edge
191). Both are tap targets, so a thumb hits the wrong control.

### M-02 — HIGH — R-03 (fixed bar covers content)
On a short phone (375x667) the hero CTAs sit under the fixed bars: hero
content bottom is 628px, the bars start at 599px. The primary "Book a
consultation" is partially covered.

### M-03 — HIGH — R-03 (fixed bar covers content)
At the true page bottom (390x844) the footer disclaimer runs 713 to 812,
and the fixed bars start at 776. The last line of the disclaimer is hidden
behind the bars.

### M-04 — not a finding (false positive)
The consent checkbox measures 22 x 44, but it sits inside a `<label>` that
is the real tap target (min-height 44, full width). No change needed.

## Checks that passed

- No horizontal overflow at 360 / 375 / 390 (scrollWidth <= clientWidth).
- Multi-column grids collapse to one column (practice, people, faq,
  contact, footer).
- Navigation collapses to a labeled "Menu" (not a bare hamburger) and the
  menu links measure 44px tall.
- Footer and contact links measure 44px tall.
- The ripple extends past the viewport but is clipped by the hero stage and
  does not create document overflow.
- Hero stage uses `100svh`, not `100vh`. The pin is intentional; kept.

## Fixes applied

1. Preview badge drops its text label on screens <= 480px (label is
   visually hidden, still the button's accessible name), so it no longer
   collides with the brief dock.
2. Hero type and spacing get a smaller mobile register, with an extra step
   for short viewports (<= 700px tall) so the CTAs clear the fixed bars.
3. The footer reserves bottom padding for the fixed bars, so the disclaimer
   is reachable above them on every screen size.
